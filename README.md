## Stack technique

- **HTML5 / CSS3 / JavaScript** (Vanilla)
- **Bootstrap 5.3** — grille et composants
- **jQuery 3.7** — interactions
- **Swiper 11** — carousels
- **WOW.js + Animate.css** — animations au scroll
- **Jarallax** — effets parallax
- **Owl Carousel 2** — carousel témoignages
- **Font Awesome 6** — icônes
